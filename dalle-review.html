What Is DALL-E Now? Legacy Models & Current Image Options

DALL·E is the name associated with earlier OpenAI image-generation models. It should no longer be used as a catch-all label for every image made in ChatGPT. OpenAI’s current image documentation describes newer GPT Image options, and its deprecation notice records the retirement of the DALL·E 2 and DALL·E 3 API models. This page keeps the familiar search term while explaining what new users and existing integrations should evaluate today.

Is DALL-E still the current image model?

No: the name describes earlier models, and OpenAI’s official deprecation notice states that the DALL·E 2 and DALL·E 3 API models were removed on May 12, 2026. New projects should consult the current GPT Image documentation. This distinction matters when reading older comparisons: a verdict about a legacy model does not automatically describe the image tool currently available in ChatGPT or the latest API endpoint.

ChatGPT images versus image API usage

For a person making occasional visuals, an interactive image workflow lets the brief develop through conversation. For a developer, the decision involves supported models, request formats, output handling and usage costs. Start by identifying which route you need. Do not copy an old API model name from a tutorial or assume your chat subscription covers a production integration. Test the documented current interface before planning a migration.

How to get a more useful image

Write the brief as you would for a designer: intended audience, subject, composition, dimensions and the text that must appear. Separate essential requirements from stylistic preferences. After the first result, ask for one focused correction at a time, such as leaving more space for a headline. For exact charts, diagrams and brand marks, use a format and tool that preserve the required precision instead of relying on a raster generation.

A migration checklist for existing projects

Inventory stored prompts, expected dimensions, editing behavior and output formats before replacing an old model. Save representative test requests and compare the new results against the needs of your application, including failure handling and cost. Update user-facing labels so they describe the product actually being used. If a supplier still advertises DALL·E access, ask which model and endpoint they mean rather than assuming the name guarantees current availability.

Frequently asked questions

What is DALL-E?

DALL·E is OpenAI’s earlier image-generation model family. Current OpenAI image tools should be identified by their documented product and model names.

Can I still call dall-e-3 in the API?

OpenAI’s deprecation documentation lists DALL·E 2 and DALL·E 3 as removed from the API on May 12, 2026. Use the current image documentation for replacements.

Are all ChatGPT images made with DALL-E?

No. The DALL·E name should not be used as a blanket label for current ChatGPT image generation.

Should I choose Midjourney or OpenAI images?

Compare the actual current workflows: reference handling, editing, visual style, usage rights and cost. A comparison against a retired DALL·E API is not enough.
